--Pandas--

판다스의 데이터 구조는 2개로
1. Series: 
2. DataFrame: 

파이썬은 자료형을 자동으로 파악해서 앞에 자료형(int, char, string..)을 안 써도 구동한다.
**COLAB Series, DataFrame 같은 문법들 앞 대문자 구분함.**

-Series <= 메뉴판처럼 만들고싶다
-------------------------------------------------------------------------------------
sr = pd.Series([17000, 18000, 19000, 20000],
               index=["피자", "치킨", "콜라", "맥주"])
print('시리즈 출력:')
print('-'*15)
print(sr)
-------------------------------------------------------------------------------------
=> 여기서 value에 index값을 해당하게 하는게 Series.
[]<-대괄호가 1개임(1차원)
--> 판다스 시리즈를 쓰는 이유: 힘들게 리스트에서 그 리스트에 붙여주는 함수를 만들 필요없이 판다스를 불러와 바로 만들수 있기 때문이다.
-DataFrame <= 액셀처럼 만들고싶다.
-------------------------------------------------------------------------------------
values = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
index = ['one', 'two', 'three']
columns = ['A', 'B', 'C']

df = pd.DataFrame(values, index=index, columns=columns)

print('데이터프레임 출력 :')
print('-'*18)
print(df)
-------------------------------------------------------------------------------------
=>시리즈보다 컬럼이라는 행렬이 하나가 더 생김.
[[]]<-대괄호가 2개임(2차원)

----------------약간 DB같은 느낌------------------
print(df.head(2)) -> df변수의 위에서부터 2개 출력
print(df.['학점'])


--Numpy--
넘파이는 파이썬에서 구동되지만 원래는 C언어로 만들어진 것이라 속도가 빠름
그래서 파이썬의 array는 속도가 느리지만 넘파이의 라이브러리에서 쓰는 array를 불러와 속도가 빠름
사진을 넣을때도 넘파이를 사용하는데 파이썬에 메트리스를 넣으면 속도가 느리게 출력되지만 이 넘파이를 쓰면 빠르게 출력이 가능하다.
